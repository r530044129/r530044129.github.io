02

造物

这一组都是实体。形体从 AI 草图或程序化节点里来，经 Blender 清理减面，切片，打印，打磨上色。

01 / 在身上生长

花枝从身体里长出来

支点是抬起的双臂，它们围出一块负空间，让整件东西不至于散掉。花纹不是贴上去的，是沿身体起伏做出的浮雕。

AI 出的形体 → Blender 整理与减面 → 切片打印 → 打磨上色。渲染图与实物同源。

02 / 折叠的人

整个身体折下去

手几乎碰到地面，脸完全被藏起来。重量都压在脚踝那一小片接触面上，所以底座不能省。

03 / 纠缠的群像

找不到起点，也找不到终点

三个人体的四肢互相穿过，支撑关系全靠彼此咬合。打印的时候最难的是找摆放角度——怎么放都要加支撑。

03

程序化生成

规则长出形态。两件事：一只花瓶，一个会换装的角色。

花瓶 / 01

一只花瓶的四十次尝试

提示词只有一句：a white abstract vase, graceful curves, shell shape, oriental esthetics。一次出一批，放在一起看，挑曲线最舒服的那条。

后面几步都不是为了"生成"，是为了能改、能打印。

从图到实物这一段，中间没有魔法：拓扑要干净，壁厚要够，摆放角度决定要不要加支撑。

角色 / 02

会换装的角色

参考《攻壳机动队》（1995）的义体比例，在 Houdini 里搭一套能换装备的角色模板：头部用属性绘制决定面罩长到哪，护甲用几组随机参数生成，蒙皮之后回引擎跑动画。

04

ArtStudio

一个自建的个人创作平台。它不是审美评测系统——审美这件事仍然由我完成。

让尝试简单一点，把时间留给挑选和想象。

真实的情况是：AI 负责批量出图和那些繁琐的步骤，我负责找参考、挑图、改提示词、推动下一轮。工程上的目标只有一个——把"想到"和"拿在手里"之间的距离缩短。

  1. 01

    找参考

    看到喜欢的就存下来，或者直接写一句想法。

  2. 02

    抽卡

    选模型与数量，一次出一批。

  3. 03

    汇总

    生成图自动同步进 Eagle，逐张比较。

  4. 04

    再抽一轮

    按选中的图改提示词，继续迭代。

  5. 05

    转 3D

    选中的图交给图生模型。

  6. 06

    减面

    Blender 里清拓扑，压到能打印的量级。

  7. 07

    切片

    Bambu Studio 里检查支撑与摆放。

  1. 01一开始是让 AI 写一个 BAT 脚本，输提示词，批量跑图——能跑，但不好管理。
  2. 02做成网页：点着用，顺手把 API 打通。
  3. 03创作有不同入口，需要不同模型，于是接入更多 API。
  4. 04接 Eagle 插件：生成图自动同步，集中看、集中挑。
  5. 05想打印，加 Blender 流程；生成模型受拓扑与复杂度限制，重点是减面。
  6. 06最后交给 Bambu Studio 切片，确认摆放与支撑。
边界 减面解决的是模型复杂度，不保证模型天然满足所有打印条件。切片这一步目前仍然是手动确认，不是"拓竹 API 自动打印"。
05

工作

同一套能力，换成项目规模。地形、建筑、工具，以及一个纯粹好玩的东西。

地形 / 01

先在山里做，再搬进引擎

侵蚀、雪线、岩石分层在 Houdini 里生成，导进 UE5 保持实时。画面里的每一个坡面都经得起走近看。

建筑 / 02

运行时也生成

同一套方案换不同资产包：里斯本、黑客帝国。运行时可以按需生成建筑内外，并支持破坏。给策划的工具是可视的：调区域、调道具、调材质。

工具 / 03

把重复的部分做成按钮

道路工具从路网生成路缘与路面，顺手吐出 MassAI 需要的路网信息；雾效工具让人直接在引擎里画范围与噪声，不用回去改参数表。

汉字 / 04

一个汉字，就是一个像素

把汉字当作像素来用。几千个字在引擎里排成街景，近看是字，退后一步才认出是地方。

技术上不复杂，难的是字重和密度：太密就糊成一片噪点。

06

其他平面

别的入口。图案、地形、舞台、面具——都不太像同一个人的东西，但它们确实是。

01 / 蜡染

布是幕，也是画框

把蜡染的图案拆开：靛蓝的底、冰裂的纹、卷云的走向，做成一套能反复用的元素，再搭成舞台。

02 / 地形

把地形当笔

雪脊的走向凑成一个正在弯腰的人。没有建模，只有参数和侵蚀。

03 / 影像

让人跳别人的舞

先用姿态估计从一段影片里解出关节，再驱动自己的模型。角色和动作不是我原创的，舞台、灯光和渲染是。

扫描回来之后泥味就没了，所以干脆反着做：不追木头，把它变成瓷器。青花的分水正好能吃下浮雕的起伏。
